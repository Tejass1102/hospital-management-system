# Hospital Management System

A full-stack, enterprise-grade Hospital Management System featuring a modern "Glassmorphism" UI and a robust Java backend. This application handles patient ward management, automated billing, and secure data persistence.

## 🚀 Tech Stack

- **Frontend:** JavaFX with CSS (Glassmorphism design)
- **Backend:** Spring Boot (Java 17)
- **Database:** PostgreSQL (Cloud-hosted via Render)
- **Build Tool:** Maven
- **Deployment:** Render (Web Service), GitHub Releases (Distribution)

## 📋 Features

- **Automated Billing:** Real-time fee calculation based on ward category (Private/General/Emergency) and duration of stay.
- **Modern UI:** Aesthetic dark-theme design with frosted glass panels and high-contrast typography.
- **Cloud-Synced:** All patient records are securely persisted in a remote PostgreSQL database, accessible from anywhere.

## 📥 How to Run (For Evaluators)

You don't need to install Java or VS Code to run this application.

1. **Download:** Navigate to the **[Releases]** section of this repository.
2. **Extract:** Download the latest `.zip` release and extract it to your computer.
3. **Launch:**
   - Navigate into the folder `Hospital-Management-System-v1/bin`.
   - **Windows:** Double-click `HospitalApp.bat`.
   - **Mac/Linux:** Execute the launch script in your terminal.
4. **Result:** The application will launch and instantly connect to the live cloud backend.
